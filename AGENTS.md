# Agent instructions

On personal setups, follow [PERSONAL_SETUP.md](./PERSONAL_SETUP.md) to install, and run `~/dotfiles/skills.sh` before reporting the install as done. Cloning alone installs nothing. Everyone else installs with `npx skills add glpecile/skills`.

This repo is public and MIT-licensed, so `skills/` holds only skills written here. Third-party skills go in the private dotfiles repo; [PERSONAL_SETUP.md](./PERSONAL_SETUP.md) says where.

## Skill descriptions

Follow [tstack](https://github.com/t3dotgg/tstack). A `description` says when to load the skill, not what is inside it: an optional short sentence on what it does, then `Use when the user asks to ...` or `Use when the user says "..."`. Keep it to one or two sentences. No feature lists and no lists of trigger keywords. Add a "Not for" clause only to name a sibling skill the agent would confuse it with. The body and the README carry the detail.
