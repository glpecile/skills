# Agent instructions

On personal setups, follow [PERSONAL_SETUP.md](./PERSONAL_SETUP.md) to install, and run `~/dotfiles/skills.sh` before reporting the install as done. Cloning alone installs nothing. Everyone else installs with `npx skills add glpecile/skills`.

This repo is public and MIT-licensed, so `skills/` holds only skills written here. Third-party skills go in the private dotfiles repo; [PERSONAL_SETUP.md](./PERSONAL_SETUP.md) says where.
