# Skills

Personal collection of [Claude Code skills](https://code.claude.com/docs/en/skills).

## Install

```bash
npx skills@latest add glpecile/skills
```

Or copy a skill folder into `~/.claude/skills/` (global) or `.claude/skills/` (per project).

## Reference

- **[delegate](./skills/delegate/SKILL.md)** — Plan at session level, delegate implementation to cheaper model subagents, verify each task with a runnable acceptance check.
